
# 8-Puzzle Solver
 An Ai agent that solves the 8-puzzle using the informed search algorthm A* with the manhattan distance heuristic. A Tkinter window shows the board and animates the solution from the start state to the goal state

## Requirements
Python 3.8 or newer
Download Tkinter
No other packages or Internet needed

## How to run
put app.py and solver.py in the same folder, open the terminal in that folder and run py app.py

## How to use

"Randomize: Randomizes the board into a new state that is always solvable."
Solve: tuns the A* solver in solver.py on the board. The window than shows every move of the solution one at a time, in order from the start state to the goal state and it shows the current moves you made. When you finish it shows the total numver of moves you took
Play: You can also click on any tile than can move to the blank space. Solve works from whatever the board looks like at that moment
